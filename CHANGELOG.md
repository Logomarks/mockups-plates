# Changelog

All notable changes to `@logomarks/mockups-plates` are documented here.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.1] — 2026-11-06

### Changed

- Renamed from `@arraypress/mockups-plates` to `@logomarks/mockups-plates`, for `@logomarks/mockups` (`>=0.4.3`, renamed from `@arraypress/mockups`); no code changes.

## [0.1.0] — 2026-11-05

### Added

- The first photo plates for `@arraypress/mockups` (0.3 or later), by name in `PLATES`, with the tools to add, check and index them.
